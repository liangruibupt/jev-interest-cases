# P6 · A3 文档逐行语义搜索 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the A3 page: semantic search over the 218-line GitHub Terms of Service with no embeddings and no generation — one Choice over 218 line ids gives per-line relevance, one Noul says whether the document answers the query at all, one speculative Noul says whether the answer spans several lines. The page highlights lines by probability and shows the "文档未涉及" verdict that a bare Choice can never produce.

**Architecture:** `shared/src/scenarios/a3-semantic-find/` builds the tagged state once (`L000| …`), builds the three questions for a query, and composes the verdict. `POST /api/a3/search` asks Jev (preset queries cached read-write, free text read-only). The page renders the document with heat highlighting and auto-scroll.

**Spec:** `docs/superpowers/specs/2026-09-22-jev-lab-design.md` §4 A3, §5 (A3 row).

## Global Constraints

- State is the whole document (≈11k tokens) sent on every query; questions carry the query text. Choice options = 218 (`L000`…`L217`) — the 255 cap is respected.
- Thresholds `FOUND 0.7 / ABSENT 0.35` and `SPANS 0.6` live in `thresholds.ts`.
- Honest SavingsCard: the assumption note says Jev is *not* cheaper than embedding search per query; the comparison is against an LLM reading the whole document.

### Task 1: shared

**Files:** `shared/src/scenarios/a3-semantic-find/{buildState,questions,thresholds,compose,index}.ts` + tests.

```ts
export const A3_LINES = GITHUB_TOS_LINES;                                  // 218
export const lineId = (i: number) => `L${String(i).padStart(3, "0")}`;
export function buildDocumentState(lines = A3_LINES): string;              // "L000| …\nL001| …"
export function buildFindQuestions(query: string, lineCount = A3_LINES.length): Questions;  // where (Choice, 218 null options), exists (Noul), spans_multiple (Noul)
export const A3_THRESHOLDS = { found: 0.7, absent: 0.35, spans: 0.6, minShow: 0.03, topN: 5 };
export const A3_PRESET_QUERIES: { query: string; note_zh: string }[];      // 6 queries (cookbook's 4 + 2)
export type A3Status = "answered" | "partial" | "absent";
export interface A3Result { status: A3Status; exists: number; spansMultiple: number; ranked: { lineId: string; index: number; prob: number; text: string }[]; highlightCount: number; naiveTop: { lineId: string; prob: number } }
export function composeFind(answers: Answers, lines = A3_LINES, t = A3_THRESHOLDS): A3Result;
```
