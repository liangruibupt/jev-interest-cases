# P12 · C3 公告重大性判断 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the C3 page: 15 synthetic company announcements (8-K style items, press releases, news snippets about fictional companies) are judged by one Jev request each — event type, materiality (4 situational levels), direction for shareholders, forward-looking, hedged language, accounting/controls, key person, boilerplate — and composed into a ranked reading list (立即看 / 今日看 / 归档) with flags. Dollar amounts and percentages are extracted by code for display only. The page states the questions Jev is **not** asked: buy or sell, valuation, price direction, how much earnings will fall.

**Architecture:** `shared/src/datasets/filings.ts` (15 items with expected lanes) and `shared/src/scenarios/c3-filings/{questions,thresholds,numbers,compose,index}.ts`. `POST /api/c3/judge` fans out one Jev request per filing. Pure Jev.

**Spec:** `docs/06-行业场景适用性.md` (金融 row).

## Global Constraints

- Judgments are about the text (what it announces, how it is worded), never about price, valuation, or forecasts.
- Thresholds in `thresholds.ts`: `readNow 1.8 / today 1.1 / flag 0.7 / hedged 0.6 / boilerplate 0.7` (readNow/today tuned on the first cache-off run: the "significant" level is 2 and Jev scored guidance cuts, lost customers and lost lawsuits at 1.9–2.2).
- Fictional companies and synthetic text; English data, Chinese UI. Cache read-write for the 15 items; `live` bypasses.

```ts
export type EventType = "guidance_change" | "executive_change" | "restatement_or_accounting" | "going_concern_or_liquidity" | "m_and_a" | "major_customer_or_contract" | "litigation_or_regulatory" | "cyber_incident" | "capital_return" | "product_or_operations" | "insider_transaction" | "routine_housekeeping" | "other";
export type ReadingLane = "read_now" | "today" | "archive";
export interface Filing { id: string; company: string; source: "8-K" | "press_release" | "news"; headline: string; text: string; expected: { lanes: ReadingLane[]; event?: EventType }; note_zh: string }
export const FILINGS: Filing[];                       // 15
export const C3_QUESTIONS: Questions;                 // event_type, materiality, direction, is_forward_looking, hedged_language, accounting_or_controls, key_person, boilerplate
export function buildFilingState(f: Filing): { company: string; source: string; headline: string; text: string };
export const C3_THRESHOLDS = { readNow: 1.8, today: 1.1, flag: 0.7, hedged: 0.6, hedgedMateriality: 0.8, boilerplate: 0.7 };
export interface MoneyMention { text: string; kind: "usd" | "percent" }
export function extractAmounts(text: string): MoneyMention[];   // display only
export interface FilingJudgment { lane: ReadingLane; rule_zh: string; materiality: number; materialityConfidence: number | null; event: { choice: EventType; confidence: number; probabilities: Record<string, number> } | null; direction: { choice: string; confidence: number } | null; flags: string[]; signals: { forwardLooking: number; hedged: number; accounting: number; keyPerson: number; boilerplate: number }; amounts: MoneyMention[] }
export function judgeFiling(answers: Answers, text: string, t?: typeof C3_THRESHOLDS): FilingJudgment;
export const LANE_LABELS_ZH: Record<ReadingLane, string>; export const EVENT_LABELS_ZH: Record<EventType, string>;
export const C3_NOT_ASKED: { question: string; why_zh: string }[];
```

Rules (ordered): accounting ≥ flag → read_now · materiality ≥ readNow → read_now · key_person ≥ flag and direction negative → read_now · boilerplate ≥ boilerplate and materiality < today → archive · materiality ≥ today → today · hedged ≥ hedged and materiality ≥ 0.8 → today (vague wording about a real matter deserves a look) · else archive. Flags: accounting / key_person / hedged / forward_looking / boilerplate when above their thresholds.
