# C1 · 作业按细则评分（教育）

**目标**：把"判作业"拆成 Jev 能做的文字判断。12 份八年级科学短答（题目：天空为什么白天是蓝的、日落是红的），Jev 一次请求回答 8 题：4 条评分细则各一个 Noul、是否切题一个 Noul、常见错误概念一个 Choice、整体水平（4 级情境描述）与表达清晰度（3 级）两个 Score。句子数由代码统计，Jev 从不数数。落在灰区、整体置信度低、细则与整体判断不一致或离题计零的作业交老师。Claude 为学生写反馈，Jev 再核验反馈是否与评分一致（B2 的"生成者与检验者分离"）。

页面：`/c1`。代码：`shared/src/datasets/essays.ts`、`shared/src/scenarios/c1-grading/{questions,thresholds,sentences,compose}.ts`、`server/src/routes/c1.ts`（`POST /api/c1/grade`、`POST /api/c1/feedback`）、`web/src/pages/C1Grading.tsx`。

## 发给 Jev 的东西

**state**：`{ assignment: { prompt, grade }, answer }`。

| id | 类型 | 英文原文（节选） | 用途 |
|---|---|---|---|
| cause_scattering | Noul | Does `answer` state that the sky is blue because the atmosphere scatters the shorter, blue wavelengths more than the longer ones? | 细则 1 |
| sunset_path | Noul | …at sunset the light travels a longer path… so the blue is scattered away…? | 细则 2 |
| names_rayleigh | Noul | Does `answer` name Rayleigh scattering as the process (an obvious misspelling such as 'Raleigh scattering' still counts)? | 细则 3 |
| evidence_or_example | Noul | Does `answer` give at least one piece of evidence, observation, or example…? | 细则 4 |
| on_topic | Noul | Is `answer` about why the sky is blue… rather than about a different topic? | 离题计 0 分 |
| misconception | Choice | none / reflects_ocean / air_is_blue / refraction_not_scattering / other_misconception（各带描述） | 点名错误概念 |
| overall | Score（4 级） | How well does `answer` respond to `assignment.prompt`? · 离题或基本错误 / 缺关键部分或有错 / 正确有小缺口 / 完整准确 | 整体水平 |
| clarity | Score（3 级） | How clearly is `answer` written, regardless of whether the science is right? | 表达与内容分开 |

**组合**（`compose.ts`）：细则 ≥ 0.7 达到、≤ 0.3 未达到、之间不确定；得分 = 达到条数；on_topic < 0.5 计 0 分；句数不在 4–6 标记过短 / 过长（代码）；错误概念置信度 ≥ 0.6 标记；**交老师**当且仅当：离题计零、有细则不确定、overall 置信度 < 0.6、细则折算水平与 overall 相差 ≥ 1.5、或错误概念的概率质量（1 − P(none)）落在 0.4–0.6。错误概念按非 none 选项的总概率判断，而不是只看最大项：none 0.45 / other 0.27 / reflects_ocean 0.27 也有 0.55 的疑点。门限可在页面拖动，浏览器重算，零推理。

- **老师只看 2/12**：E06（离题计零，零分必须由人确认；顺带一提 Jev 对这篇离题作答的错误概念分布很散，none 只有 0.37，离题时不计）和 E07（细则 1 落在 0.48 灰区：只说"散射"没说散射什么）。两个都值得人看。
- 表中数值来自关缓存的一次运行；页面回放的是提交缓存里的另一次运行，各项相差 ≤ 0.05，结论不变。
- E03 说明 Jev 按字面执行题目说明：说了"拼错也算"，它就给 0.99。

## 页面上的一次反馈（E02，Sonnet 5）

Claude 6.2 s、$0.0023：

> Great work explaining why the sky is blue and why sunsets turn red-orange—your point about sunlight traveling through more atmosphere at sunset, causing blue light to scatter out, is spot on! You also gave a nice supporting example with the yellowish noon Sun. One thing missing: you should name the specific process, called Rayleigh scattering, which describes why shorter wavelengths like blue scatter more.

Jev 核验：与评分一致 **0.95**、针对具体内容 **0.98**、语气得当 **0.94**。只夸了做到的三条，只提了没做到的那一条。

## 试一试

1. 把"达到 ≥"从 0.7 拉到 0.9：看还有谁被送去老师（细则值多在 0.93–0.99，基本不变——说明这批判断很干净）。

3. 改 `essays.ts` 里 E03 的 "Raleigh" 为 "Rally"，看 names_rayleigh 掉多少。
4. 把 `overall` 的四级描述改成 "0 / 1 / 2 / 3" 这种数字级别，对比分布（A1 预置 5 的教训）。

## 陷阱

- 句子数、字数、算术题对错永远在代码里；Jev 不数数。
- 错误概念是封闭清单：清单外只能落到 other_misconception，老师看到它就该去读原文。
- 英文作答准确率最高；中文作文要先在小样本校验置信度（A1 预置 7）。
- 评分细则写得越具体，Noul 越干净：本例把"证据"写成了带例子的描述（列举了黄太阳、火星 / 月球、牛奶水）；E04 / E05 / E11 用的是清单外的例子，仍得 0.92–0.97，说明例子起的是示意作用而不是白名单。
- 门限附近会漂移（见 A3 / B3）：0.4–0.6 的错误概念、0.3–0.7 的细则都交人，不要自动出分。
