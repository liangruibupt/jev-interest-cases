# C5 语义音乐盒：把语义判断变成可听见的控制信号

## 新的组合

既有案例集中在理解、检索、路由与核验。这里探索另一个方向：
**Jev 不写文字、不生成音频，却能为程序化创作提供语义控制信号。**

输入英文画面描述，例如雨夜车窗、玻璃温室、夜跑脉冲、失重漂浮。
一次调用给出以下判断，再由代码生成完整的四小节器乐。

| 问题 | 原语 | 程序如何使用 |
| --- | --- | --- |
| timbre | Choice | 选择暖弦、玻璃音、拨弦三种合成音色之一 |
| energy | Score，0–4 | 归一化后映射默认速度；显式 BPM 数字由代码解析 |
| brightness | Score，0–4 | 映射本地低通滤波器的截止频率 |
| density | Score，0–4 | 调节确定性音序中音符出现的密度 |
| tension | Score，0–4 | 选择较舒展或较悬疑的音阶与和声配置 |
| percussion | Noul | P(需要鼓点) ≥ 0.65 时启用鼓点，不能把概率当音量 |
| silence | Noul | P(明确要求完全静音) ≥ 0.70 时不安排任何音符 |

阈值与映射是此创作工具的可审阅设计常量，不是 TypeSafe 官方推荐阈值。
主观音乐偏好可以有多个合理解，不因 Choice 分布分散就强制阻断。
原始概率、置信度和问题定义都保留在页面检视器中。

## 哪些事情不是 Jev 做的

- 速度的字面数字解析、范围限制与音符时序。
- 音阶、和声、音符选择、种子变奏及波形合成。
- 监听音量、PCM 峰值限制与 WAV 编码。
- 本地滑杆、音色切换、变奏、试听与下载。

编曲根据描述种子和控制参数确定，相同参数与种子重建相同乐谱。
这是参数驱动的器乐小品，不是无限长度音乐生成器，也不会生成歌词、人声或复刻具体歌曲。
初始预览明确标记为“手动预置音色”，不会把手工参数冒充真实 Jev 响应。

## API 与数据边界

`POST /api/c5/interpret` 接收 `{ brief, live? }`。
服务端固定七个问题，限制描述 5–1500 字符，不接受客户端自定义执行逻辑。
只有四个公开预置可写入现有可提交缓存；自定义描述使用只读缓存，
避免用户自由输入出现在版本库中。API Key 仅由现有服务器环境加载。

模型返回必须包含合法枚举、有限数值与正确取值范围；无效输出返回 502，
不会被转换成不受约束的音频参数。

## 播放与导出

使用浏览器原生 Web Audio API 合成（无麦克风权限、无音频上传）。
AudioContext 只在点击播放时创建；模型请求完成不会自动发声。
编辑音色会停止旧音频，避免画面显示新参数却继续播放旧结果。
WAV 为 44.1 kHz、双声道、16-bit PCM，包含释放尾音；监听音量不改变导出文件。

## 验证

- 共享层：问题合法性、参数归一化、Noul 阈值、BPM 解析、静音、确定性、取值边界与 WAV 格式。
- 路由：输入校验、单次七题调用、公开/私有缓存策略、畸形上游输出。
- 真实调用：`npm run smoke -- c5`，四个公开预置（缓存命中会明确显示）。
- 浏览器：桌面/移动端布局、琴卷帘非空、播放与停止、WAV 非静音与无削波，
  并确认手动混音和导出没有新增 Jev 请求。

成本对比只估算“同一组参数判断”的 JSON 输出，不比较完整音乐模型，
也不声称只有 Jev 才能在调用后复用参数。

## 本次实测

模型：`jev-1.13.0`。四条公开预置首次真实调用合计约 **$0.00015834**，
耗时范围 **418–827 ms**（当前机器与网络，不是服务 SLA）。

| 预置 | 音色 | BPM | 鼓点 | 原始调用耗时 |
| --- | --- | --- | --- | --- |
| 雨夜车窗 | warm | 62 | 关闭，P=0.19 | 827 ms |
| 玻璃温室 | glass | 103 | 关闭，P=0.10 | 510 ms |
| 夜跑脉冲 | pluck | 124，代码读取字面 BPM | 开启，P=0.98 | 521 ms |
| 失重漂浮 | glass | 58 | 关闭，P=0.13 | 418 ms |

这些是特定描述下的主观映射，不是音乐质量准确率。

- C5 专项：17 项测试通过；当次完整测试：48 个文件、193 项通过。
- 类型检查与生产构建通过；现有整体 bundle 仍有大于 500 kB 的提示。
- 浏览器：真实缓存回放、播放/停止、移动游标、无额外推理的混音和变奏、
  手机布局、模拟 503 后恢复。
- `docs/examples/c5-rain.wav`：真实浏览器合成的 17.084 秒双声道 44.1 kHz PCM，
  峰值约 0.147、RMS 约 0.032，无削波。
- `docs/results/c5-browser-qa.json` 与 `docs/screenshots/c5-sound-*.png` 保存验证记录。
- 服务运行后可重跑：`JEV_UI_URL=http://127.0.0.1:5174 node scripts/verify-c5-browser.cjs`。
